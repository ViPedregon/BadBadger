Portrait files use the saved stable identity id as their filename:

- victor_gravenholt.png
- matilda_ash.png
- horace.png

PNG, WebP, and JPG are supported (in that preference order). Use a 3:4 portrait
crop; the card fills its frame with object-fit: cover. Images are served through
the same authenticated application as the game. Until a file is supplied, the
card shows initials. Portraits are presentation assets and can be added to an
existing save without starting a new game.
